# 忌口与搭配规则

> 供 skill 运行时查阅。**全部数据来自接口实测**（门店 1450056 / 1450713，2026-10-22~23）。
> 核心原则：**不静默降级** —— 满足不了必须说清楚。

---

## 1. 忌口能力实测边界

对门店全部在售单品（102–105 款）逐一核对后，确认：

| 忌口 | 菜单支持度 | 可行方案 | **必须告知用户的话** |
|---|---|---|---|
| **吃素 / 素食** | ❌ 无素食主餐 | 见 §2 兜底库；正餐位用「单人餐 + 大米风味麦旋风」拼 | 「麦当劳目前没有素食主餐，只能用小食和甜品凑，主食需要另行解决」 |
| **不吃辣** | ⚠️ 仅能换酱料 | 改选本身不辣的款（麦香鸡/巨无霸/板烧鸡腿堡） | 「辣味来自酱料本身，系统内无法完全去除，建议换成不辣款」 |
| **不要香菜** | ⚠️ 可去 | 部分单品含「切块生菜」，可用特调去掉 | 「可以去掉生菜」 |
| **过敏（麸质/乳/坚果等）** | ❌ 无法标注 | — | 「系统内无法标注过敏原，必须当面与门店确认」 |
| **少油 / 控热量** | ✅ 支持 | `list-nutrition-foods` 有 160 项完整数据 | 见 §5 |
| **无糖** | ✅ 支持 | 换无糖可口可乐(903071)、纯牛奶(903755) | — |
| **不想要奶** | ⚠️ 仅部分 | 燕麦奶(510488)、无糖可乐、苹果汁 | 「饮品可换燕麦奶或无糖可乐」 |

**关键路径**：`9900010341 鸡肉汉堡随心选单人餐` 的 R3 小食轮里直接包含 `521917`，
这是素食忌口**唯一的正餐级兜底** —— 可拼出「单人餐 + 无荤甜品」形态。

### 荤素混合怎么配
人数 N 中有 K 人吃素：
- **K = 1**：点 1 份单人餐（R1 换成不辣款 + R3 选 `521917`）+ 其余 N-1 人正常套餐
- **K ≥ 2**：K 人各点「单人餐 + 521917」，或 K 人各点「经典小食2件(9900011822)」+ 玉米杯 + 派
- **全部吃素**：只能小食 + 甜品组合，**必须在方案里明确说明主食缺失**

### 4.3 搭配策略

1. **按人数定位档位**：1→单人餐，2→双人餐，3→三人餐，4→四人餐
2. **逐 round 检查忌口**，冲突 round 用该 round 内允许的替换项解决
3. **饮料轮**优先选无糖可乐(`903071`) / 纯牛奶(`903755`,+0.5) / 苹果汁(`901027`,+2)
4. **总价** = 套餐折扣价 + Σ(diffPrice) + 额外单点
5. **差 1–2 人**时，宁可「1 个大套餐 + 单品补充」，不要硬凑更大的套餐

## 6. 搭配话术模板

### 方案呈现（Step 7 必须包含）

```
【N 人份方案】  门店：XXX（营业 06:30–23:00）

商品                        数量   小计
龙焰鸡腿堡四件套              1    36.9
王牌炸鸡任选2                 1    19.9
薯条                          1    15.5
────────────────────────────────
商品小计                          72.3
配送费                            6.0
打包费                            3.8
────────────────────────────────
合计                            82.1 元   （原价 92.0，省 9.9）

优惠券：19.9元王牌炸鸡任选2（减 10.1 元，10-23 23:59 到期）
忌口：✅ 全部满足  /  ⚠️ 部分满足（详见下方）
```

### 忌口满足情况的写法

**全部满足**：
```
忌口：✅ 3 人份均不含辣味与香菜，已确认
```

**部分满足（必须明确指出）**：
```
忌口：⚠️ 部分满足
  · 不吃辣 —— 已全部换成不辣款（巨无霸 / 麦香鸡 / 板烧鸡腿堡）
  · 1 人吃素 —— ⚠️ 麦当劳无素食主餐，该位安排「单人餐 + 泷愿成真麦旋风（大米风味）」
                属甜品类，主食无法满足，建议另行准备
```

**完全无法满足（先问用户）**：
```
忌口：❌ 无法满足
  · 纯素且要求正餐 —— 菜单内无任何素食正餐选项。
    可选：A) 用小食甜品凑（玉米杯+派+麦旋风）  B) 改为非素食  C) 换一家餐厅
    请选择其一，或告诉我不点这个。
```

## 7. 硬性规则清单

1. 忌口无法满足 → **必须显式说明**，不得静默替换商品
2. 忌口信息**同时写入订单 `remark`**，供门店人工确认
3. 荤素混合 → 按人数拆分，荤食走正餐、素食走兜底库
4. 全部忌口都无法满足 → **先问用户**再继续
5. 甜品标注要诚实：把麦旋风当"正餐"时必须说明它是甜品
6. 辣度判定以酱料为准，不要因为名字没有"辣"就断定不辣
7. 多人套餐严格遵守每个 round 的 min/max 数量
8. 金额单位是分，展示除以 100
